# Country Clash

Proyecto final DAM desarrollado en Unity 2D.

## Descripción

Country Clash es un videojuego competitivo en 2D donde el jugador representa un país y debe recoger únicamente los objetos asociados a su nación mientras compite contra bots controlados por IA básica.

El proyecto incluye:

- Sistema de puntuación
- Bots automáticos
- Ranking final
- Tilemaps y colisiones
- Animaciones
- Ranking online
- Base de datos MySQL cloud
- API PHP conectada con Unity

## Tecnologías utilizadas

- Unity
- C#
- PHP
- MySQL
- Railway
- XAMPP
- TextMeshPro

## Arquitectura

Unity → API PHP → MySQL Cloud
